## Log (one line per step)
- Phases 1-2: Claude Code built the skeleton (config, JSON logs, errors, health/ready, Dockerfile, compose, CI), the job API (JSON + upload), idempotency, signed download links, auth + rate limit, worker with atomic claim, signed callbacks and 48 tests (47 pass locally, 1 MinIO test runs only in Docker/CI).
- Phases 3-4: Claude Code wrote intake.py (download limits, ffprobe real-type checks, 48 kHz mono WAV), tts.py (kokoro + mock adapters), transcribe.py (faster-whisper + mock, silent / music-only checks), scenes.py (scene-splitting algorithm), outputs.py (SRT), a first render.py (colour placeholders + burned captions), runner.py (real worker stages) and the tests; installed the ML packages in my .venv and ran one real Kokoro + Whisper job locally. I reviewed and ran it.
- Phases 5-7: Claude Code wrote understand.py (groq / rules / mock, sense dictionary, statistic / name / brand / sensitive detectors, Groq-to-rules fallback), safety.py, providers/ (pixabay_video, pixabay_image_motion, wikimedia with a CC0 / PD / CC BY-only licence filter, generated motion cards, mock, disabled pexels, mid-job override file), rank.py (open_clip scoring + measurable selection rule, ffprobe-verified downloads), the new render.py (time fitting, salient 9:16 crop / blurred fit, Ken Burns, brightness/colour normalisation, segment cache), qa.py, timeline/manifest builders, an SSRF guard, and 106 new mock tests (213 total: 212 pass, 1 MinIO test runs only in Docker/CI). It ran one real local job (Kokoro, Whisper, Groq, Pixabay, CLIP); that run exposed two bugs (full-range yuvj420p output from JPEG photos; Wikimedia returning 403 without a contact in the User-Agent), which it fixed and covered with tests. I reviewed and ran it.
- CI fix + 3 weak spots: Claude Code fixed the Docker/CI build (torch 2.14.1 + torchvision 0.29.1 installed together from the CPU index and pinned in requirements-ml.txt, pip --retries 5 --timeout 60 plus a 3-try loop for the torch step, pip cache mount, one image build in compose and one Buildx build with GitHub Actions layer cache in CI), added a CLIP logo check (reject/penalise by logo-vs-scene gap, calibrated on 31 hand-labelled real Pixabay previews), a CLIP subject-aware crop (left/centre/right/salient windows scored per frame, blurred fit fallback, choice recorded in timeline.json), Groq temperature 0 + full understanding stored per scene with a fingerprint and reused on re-render, and 14 new mock tests (227 total: 226 pass, 1 MinIO test runs only in Docker/CI). It re-ran the real local job three times; the runs showed that Groq at temperature 0 still varies its wording between jobs, that a too-low crop tie margin cut the subject (raised to 0.03), and that one Apple logo on a laptop still got through as "penalised". The Docker/CI changes were not run locally (no Docker on my PC). I reviewed and ran it.
- Phases 8-9 + logo fix: Claude Code added a logo test on 3 frames of every DOWNLOADED clip (a rejected frame rejects the clip; `logo_check` with thumbnail + frames in timeline.json), the clip swap (POST .../scenes/{scene_index}/swap: next_best, provider + clip_id, or clip_url via the SSRF-safe downloader with Pixabay / Wikimedia licence checks or user_supplied licence fields; a swap cache saved by the full job; only that scene re-rendered per ratio; swap history + swap time vs full render time in timeline/manifest; JOB_NOT_READY and NO_ALTERNATIVE_CLIP codes; a small SQLite migration), forced visual_hint as the first query for Groq too, openapi.yaml (OpenAPI 3.1) with a contract test against the app's routes, tools/batch_run.py, scripts/test.ps1, README.md with settings + error tables (checked by tests) and 38 new mock tests (265 total: 264 pass, 1 MinIO test runs only in Docker/CI). It ran one real local job ("Saving money...", 16:9 + 9:16): full render 108.9 s, swap of scene 2 with next_best 23.5 s (only scene 2 changed). The run also showed that the existing thumbnail logo check rejects most Pixabay video candidates (not yet re-calibrated). Docker was not run locally. I reviewed and ran it.
